# Запуск версии 2

Python 3.11, главный файл main.py. Сторонних библиотек нет.
Переменная TELEGRAM_BOT_TOKEN (также поддерживается BOT_TOKEN) задаётся в панели.
DATA_DIR=/app/data — постоянное хранилище прогресса. На ПК по умолчанию ./data.
Старый progress.sqlite3 автоматически копируется в data при первом запуске.
Включите «Собственный Dockerfile» на BotHost для предсказуемого запуска.
Домен, webhook и права администратора Telegram не нужны.
Для приватного GitHub-репозитория хостингу нужен доступ чтения кода.
Изменение Python-кода не исправляет ошибки Git-авторизации на сервере хостинга.
Один экземпляр: после успешного переноса остановите бот на ПК.
Проверки: python -m unittest -v.

# Татарский каждый день

Готовая к подключению стартовая версия Telegram-бота. Python 3.10+, без сторонних библиотек.

## Что работает

- 20 заданий в день, по четыре кнопки ответа; перевод в обе стороны.
- Пять тем от приветствий до первых предложений: 100 шаблонов заданий.
- Пояснение после ответа. Ошибка засчитывается как выполненное задание.
- При 16 правильных ответах из 20 следующая тема открывается завтра.
- При меньшем результате завтра повторяется тема. После последней темы — её закрепление.
- Прогресс и текущий урок сохраняются в SQLite после перезапуска.
- После вчерашней невыполненной нормы — одно напоминание в день начиная с 19:00.
  Если сегодняшняя норма уже выполнена, напоминания нет.
- По умолчанию сутки и напоминания считаются по UTC+3. Можно задать UTC_OFFSET.
- /pause и /resume управляют напоминаниями; /progress показывает статистику.
- Старые кнопки и повторные нажатия не увеличивают счётчик.

## Запуск в Windows

1. В Telegram откройте https://t.me/BotFather, отправьте /newbot и создайте бота.
2. Сохраните токен у себя. Не публикуйте его и не включайте в архив проекта.
3. Установите Python 3.10+ либо используйте Python из среды Codex.
4. Откройте PowerShell в этой папке и выполните:

```powershell
$env:TELEGRAM_BOT_TOKEN = Read-Host 'Токен BotFather' -MaskInput
python bot.py
```

В Windows PowerShell 5 вместо -MaskInput можно задать переменную через системные настройки.
Если команда python запускает Python 2, используйте `py -3 bot.py`.
В этой среде есть Python по адресу:
`C:\Users\AWBG\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`.

5. Откройте своего бота и нажмите «Запустить» (/start).
6. Процесс должен работать постоянно, чтобы приходили напоминания. Для круглосуточной
работы перенесите папку на постоянно включённый компьютер или сервер, задайте токен
в окружении и настройте автоматический перезапуск. Запускайте только один экземпляр.
Webhook для этого бота должен быть выключен: здесь используется getUpdates.

## Проверка

`python -m unittest -v` — проверка нормы, переходов, повторных кнопок и напоминаний.
Реальное подключение к Telegram требует вашего токена; без него не проверено.
При перезапуске бот отправляет положенное напоминание, если уже наступило 19:00.

## Содержание и границы версии

Это стартовый учебный набор, а не полный курс A1–B2. Темы постепенно переходят
от слов к предложениям; пока нет аудио, произношения и интервального повторения ошибок.
Перед широким использованием татарские формулировки и методику должен проверить преподаватель.
Новые темы добавляются в course.py. Интерфейс сейчас на русском, изучаемый язык — татарский.
Дневную норму нельзя принудительно выполнить за человека: бот учитывает её и напоминает.
База хранит Telegram ID, даты и результаты. Для удаления данных остановите бот и удалите
progress.sqlite3 (это удалит прогресс всех пользователей); сохраняйте резервную копию при переносе.
